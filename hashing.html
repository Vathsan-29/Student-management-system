Hash table search

Division method with linear probing

Data structureHash table
Syllabus unitUnit V
Menu option13

A student ID goes to slot ID % 101. A colliding key is placed in the next free slot, and the table view marks every collision.

Algorithm

6.7 Hashing Using the Division Method and Linear Probing

A colliding key is placed in the next free slot of the table. HASH(key) = key % TABLE_SIZE (TABLE_SIZE = 101) INSERT(key) 1. index = HASH(key) 2. While table[index] is occupied index = (index + 1) % TABLE_SIZE 3. table[index] = key SEARCH(key) 1. index = HASH(key) 2. While table[index] is occupied If table[index] == key, return index index = (index + 1) % TABLE_SIZE 3. Return NOT_FOUND

Source code
7.14 Hash Table Search (Option 13)
static void hash_menu(void)
{
    int choice, id, slot, probes, i, shown = 0;

    printf("\n 1. Search a student ID using the hash table\n");
    printf(" 2. Show the hash table\n");
    choice = read_int("Enter your choice: ");

    if (choice == 1) {
        id = read_int("Enter student ID: ");
        slot = hash_search(id, &probes);
        if (slot >= 0)
             printf("Found in slot %d after %d probe(s): %s\n",
                    slot, probes, student_name(id));
        else
             printf("Not found (%d probe(s) made).\n", probes);
    } else if (choice == 2) {
        printf(" TABLE SIZE = %d, hash(key) = key %% %d\n", TABLE_SIZE, TABLE_SIZE);
        for (i = 0; i < TABLE_SIZE; i++)
             if (hash_table[i] != 0) {
                 printf(" slot %3d : %-12d %-18s home slot %d%s\n", i,
                        hash_table[i], student_name(hash_table[i]),
                        hash_table[i] % TABLE_SIZE,
                        (hash_table[i] % TABLE_SIZE != i) ? " (collision)" : "");
                 shown++;
             }
        if (shown == 0)
             printf(" The table is empty.\n");
    } else {
        printf("Invalid choice.\n");
    }
}
