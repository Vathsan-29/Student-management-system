Searching a student

Linear, binary and BST search

Data structureArray, list and BST
Syllabus unitUnits I, II, III
Menu option3

The same student can be found three ways: linear search in the linked list, binary search in a sorted copy of the IDs, and search in the binary search tree. The program shows how many comparisons each one made.

Algorithm

6.4 Student Search Using a Binary Search Tree

The key is compared with the root and the search moves to the left or right subtree. SEARCH(root, key) 1. If root == NULL, return NOT_FOUND 2. If key == root->id, return root 3. If key < root->id return SEARCH(root->left, key) Else return SEARCH(root->right, key)

7.8 Search Student (Option 3)
static void print_student(Student *s)
{
    printf(" ID: %d | Name: %s | Department: %s | Year: %d\n",
           s->id, s->name, s->dept, s->year);
}

static void search_student(void)
{
    int choice, id, steps = 0;
    Student *s = NULL;

    printf("\n 1. Linear search (linked list)\n");
    printf(" 2. Binary search (sorted array)\n");
    printf(" 3. Binary search tree\n");
    printf(" 4. Show all IDs in sorted order (BST inorder)\n");
    choice = read_int("Enter your choice: ");

    if (choice == 4) {
        if (root == NULL)
            printf("No students registered yet.\n");
        else {
            printf(" %-12s %s\n", "ID", "NAME");
            bst_inorder(root);
        }
        return;
    }
    if (choice < 1 || choice > 3) {
        printf("Invalid choice.\n");
        return;
    }
    if (head == NULL) {
        printf("No students registered yet.\n");
        return;
    }





    id = read_int("Enter student ID to search: ");

    if (choice == 1) {
        s = find_student(id, &steps);
    } else if (choice == 2) {
        int ids[MAX_STUDENTS], n = 0, i, j, key, low, high, mid;
        Student *t;

        for (t = head; t != NULL; t = t->next)       /* copy IDs */
             ids[n++] = t->id;
        for (i = 1; i < n; i++) {                    /* insertion sort */
             key = ids[i];
             j = i - 1;
             while (j >= 0 && ids[j] > key) {
                 ids[j + 1] = ids[j];
                 j--;
             }
             ids[j + 1] = key;
        }
        low = 0;
        high = n - 1;
        while (low <= high) {                        /* binary search */
             mid = (low + high) / 2;
             steps++;
             if (ids[mid] == id) {
                 s = find_student(id, NULL);
                 break;
             } else if (ids[mid] < id) {
                 low = mid + 1;
             } else {
                 high = mid - 1;
             }
        }
    } else {
        s = bst_search(id, &steps);
    }

    if (s != NULL) {
        printf("Student found after %d comparison(s):\n", steps);
        print_student(s);
    } else {
        printf("Record not found (%d comparison(s) made).\n", steps);
    }
}
